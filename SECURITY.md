# Security

Luna Max Coder is a workflow plugin, not an operating-system security
boundary. Review the confirmation and capability rules before granting a task
any external or high-impact effect.

## Report a vulnerability

If this repository has GitHub private vulnerability reporting enabled, use
**Security** → **Advisories** → **Report a vulnerability**. If that option is
not available, contact the repository maintainers through the repository's
private reporting channel. Do not open a public issue for an undisclosed
vulnerability.

Do not include API keys, access tokens, passwords, private keys, personal data,
or other secrets in a report. Redact secrets before sharing logs or samples.
Provide only the details needed to reproduce the issue, its impact, affected
files or versions, and a safe contact path for follow-up through the private
channel.

Wait for a maintainer response before public disclosure. Maintainers may ask
for a minimal reproduction or additional evidence; do not send credentials or
grant broader permissions to produce it.
